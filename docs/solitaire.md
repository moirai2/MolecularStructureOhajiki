# MolSolitaire（分子ソリティア）

**日本語** | [English](./solitaire.en.md)

> 🎴 **資源有限のソロエンジンビル**：弾いたおはじきは戻らない。元素枠で軽減を積み重ね、できるだけ少ないおはじき消費で Lv3 カードを狙う。

おはじきを弾いて分子構造カードを集め、元素枠で軽減を積み重ねながらLv3カードを目指すひとり用エンジンビルディングゲームです。
消費するおはじきが少ないほど高スコア。資源は有限——盤外に出したおはじきは戻りません。

- **人数:** 1人（ソロ専用）
- **時間:** 15〜30分
- **対象:** 10歳以上

> 📘 **おはじきの色とカードの読み方は [COMPONENTS.md](./COMPONENTS.md) を参照**
> 📗 **化学用語（元素・分子式・官能基など）の解説は [GLOSSARY.md](./GLOSSARY.md) を参照**

---

## コンポーネント

- 分子構造カード（Lv1: 20枚、Lv2: 20枚、Lv3: 10枚）
- 元素カード 5枚（炭素・水素・酸素・窒素・その他）
- おはじき 5色 × 各10個（計50個）
- 発射台カード 2枚（おはじきを弾く位置）
- タイトルカード 1枚（発射台の間に挟むスペーサー）
- **滑り止めマット 1枚**（カードが動かないように敷く。プレイには必須）

## セットアップ

下図のように配置します（[拡大図](./solitaire_setup.svg)）。

![MolSolitaire セットアップ図](./solitaire_setup.svg)

0. **滑り止めマット** をプレイエリアに敷く。カードが弾かれて動かないようにするための必須コンポーネント
1. **元素カード5枚** を手元（プレイヤーから見て手前）に横一列に並べる。この列を **「元素枠」** と呼び、後で回収した分子構造カードを置いて元素コストを軽減する
2. **Lv1カード** をシャッフルし、9枚を表向き・横向きで **3×3グリッド** に配置する
3. **Lv3カード3枚** を3×3グリッドの**外側・奥側**（グリッドに隣接させ、プレイヤーから見て遠い辺に沿って）並べる
   - 中央の1枚は**表向き** = このゲームで目指す目標カード
   - 左右の2枚は**裏向き**（スペーサー）
4. **Lv3カード3枚（裏向き）** を3×3グリッドの**外側・手前側**（グリッドに隣接させ、プレイヤーに近い辺に沿って）並べる（スペーサー）
   > スペーサーは誤判定防止のセーフティネット（詳細は[設計ノート](#設計ノート)）。
5. **発射台2枚** を縦向きで一番手前に置き、間に **タイトルカード** を挟む（タイトルカードは発射台同士を離すスペーサーとして使い、発射エリアの幅を広げる）。おはじきはどちらかの発射台からしか弾けない
6. **Lv1・Lv2・Lv3 の残りカード**をレベル別の山札として脇へ積む。**残り4枚のLv3カードは標準ルールでは使用しないが、撤去せず山札として置いておく**（プレイヤーが独自のバリアントで使うこともできる）
7. **おはじき（5色 × 各10個＝50個）** を手元に置き、元素カードの上に色別に分けて配置しておく

## 用語

**盤上・盤外の判定:**
> **盤面** = 3×3 の回収対象カード（Lv1 / Lv2 / 表向き目標 Lv3）。Lv3スペーサー（裏向き）は盤面外。
> おはじきが静止した時点で、**マットに触れていなければ盤上**、触れていれば**盤外**（横から見て判断）。

**またがりおはじき（量子力学モデル）:**
> 複数のカードに触れている場合、触れているカード全てに乗っている扱い。回収判定の瞬間にプレイヤーがどのカードに割り当てるか選んで確定する。カード取得時、そのカードに触れているおはじきは全て捨て場へ（詳細は[1手番の流れ](#手番の流れ) step 2参照）。

## 1手番のフロー

ソロは「自分の手番」を繰り返します。1手番の流れは以下の通り。

```
1. 手元のおはじきを1個、発射台から弾く

2. おはじきの行き先を確認する
   - **回収対象カード**（Lv1 / Lv2 / 表向きの目標Lv3）に乗っている → そのカード上に残る
   - **裏向きのLv3カード（スペーサー）のみ**に乗っている → **プレイヤーが選択**：
     - **盤外として扱う**（捨て場へ送る）
     - **スペーサー上に残す**（次の手番以降、別のおはじきで弾いてグリッドに押し戻せる。押し戻されたおはじきが回収対象カードに乗っていれば「盤上」として扱う）
     > ★ 手前スペーサー上のおはじきは「死に体ではない」。あえて残しておいて狙い直すか、即座に捨てて次に備えるか——リスクとリターンを読む判断がスキルになります。
   - **盤外**（どのカードにも触れていない） → 捨て場へ（**step 3 の回収判定は通常通り行う**。以前からカードに乗っているおはじきで条件が揃えば回収できる）
   - **回収対象カードとスペーサーにまたがっている場合**: 回収対象カードに乗っている扱い（スペーサーへの接触は無視）。上手い人はスペーサーをかすめて回収対象を狙える

3. カード回収判定をする
   - 判定の前に手元のカード（元素枠配置中のカードも可）を分解してもよい
     （**分解** = カード1枚を捨て場に出し、その元素の含有数分を
     今手番の判定で一括免除する。詳細は[分解セクション](#分解カード消費による一括免除)）
   - **連鎖回収（step 4）の各サイクルでも、次の判定を始める前にさらに分解を宣言できる**
   - 盤上におはじきが1個以上乗っている**すべてのカード**を1枚ずつ確認し、
     おはじき＋元素枠の軽減＋分解の合算で条件を満たすかチェックし、
     満たすカードを手元に獲得する。
     **（今弾いたおはじきだけでなく、以前の手番から乗ったままの全おはじきも含みます）**
   - **取得した瞬間、そのカードに触れているおはじき（またがり含む）は全て捨て場へ**。
     またがりおはじきは取得時に確定するため、別カードの判定材料には使えなくなる。
   - 取得順はプレイヤーが選べる（A→B か B→A で結果が変わる場合がある）

4. 「元素枠」を整理する
   - 回収済みカードを元素枠に配置 / 入れ替えできる
   - 枠が埋まっている場合は元素枠から1枚を抜いて手元（ストック）へ戻す
   - **★連鎖回収**: 元素枠の配置・入れ替えで軽減量が変わり、すでに
     おはじきが乗っているカードの条件が新たに満たされたら、
     そのカードも同じ手番で回収できる。
     **新たに回収条件を満たすカードが無くなるまで連鎖を繰り返す**
     （回収→元素枠整理→再判定…をループ）
   - **入れ替えで軽減が下がった場合**: 以前の手番からおはじきが乗っていたカードでも条件を外れれば取れない（入れ替えは取り消せない）

   > **連鎖例**: 水 H₂O（H=2, O=1）を回収 → **酸素枠**に配置（O軽減=1）。
   > 盤上のエタノール C₂H₆O（C=2, H=6, O=1）にすでに黒×2・白×6が乗っていた場合:
   > C=2は黒×2でOK、H=6は白×6でOK、O=1は**枠軽減で自動達成** → 同じ手番でエタノールも回収可能！
   > さらにエタノールを水素枠に配置（H軽減=6）すれば、次の手番以降の連鎖が一気に広がります。

5. 空いたマスを補充する
   - **空いたマスごとに、Lv1またはLv2の山から好きなカード1枚を選んで**
     表向きで配置する（自動補充ではなく、毎回プレイヤーが選ぶ）
   - **Lv3山札は補充に使わない**（標準ルール）

6. 手番終了
```

## 回収判定（コアメカニクス）

盤上におはじきが1個以上乗っている **すべてのカード** について、**各元素ごとに**以下を計算します。

```
必要量 = カードの分子式に含まれる、その元素の個数
免除量 = (そのカードに触れているおはじきのうち、その元素の色の個数)
       + (元素枠に置かれた分子構造カードの、その元素の個数)
       + (今手番で宣言した分解カードの、その元素の個数)

分子式に含まれるすべての元素について 必要量 ≤ 免除量 → 回収成功
```

> ※ またがりおはじきは、判定時には「触れているカード全てに乗っている」扱い（量子重ね合わせ状態）。**カードを取得した瞬間にそのカードのものとして確定し、捨て場へ送られる**ため、別カードの判定材料には使えない（[盤上・盤外の判定](#盤上盤外の判定) 参照）。

### 回収例（軽減・分解なしの場合）

カード上のおはじきだけで成立するかを見ます。

| カード | カード上のおはじき例 | 判定 |
|--------|------------------|------|
| 水 H₂O (H=2, O=1) | 白×2、赤×1 | ✅ 回収（H・O両方満たす） |
| 水 H₂O (H=2, O=1) | 白×3、赤×0 | ❌ O=0 で不足 |
| 水 H₂O (H=2, O=1) | 白×2、赤×1、黒×1（不要な色） | ✅ 回収（黒は無効だが妨げない） |
| 水 H₂O (H=2, O=1) | 黄×3（不要な色のみ） | ❌ 免除量 H=0, O=0。黄は「その他」なので H にも O にも貢献しない |
| メタン CH₄ (C=1, H=4) | 黒×1、白×4 | ✅ 回収 |
| メタン CH₄ (C=1, H=4) | 黒×1、白×3 | ❌ H=1不足 |

**例（色が合わないおはじきを弾いた場合）**:
> 手元に黄色おはじきしか残っていない。盤上の水 H₂O に白×1・赤×0 が乗っている。
> → 黄色おはじきを弾いて H₂O に乗せた。
> → カード上: 白×1・黄×1。H₂O の回収判定: H 必要2 / 免除=白×1=1 → **H不足**。黄×1 は H にも O にも貢献しない。
> → 回収できない。次の手番で白または赤を乗せれば条件に近づく（黄は引き続きカード上に残る）。

## 元素枠への軽減

回収した分子構造カードを**5枚の元素カード（炭素・水素・酸素・窒素・その他）のいずれかに重ねて配置**することで、その元素についてのコストを常時軽減します。元素カードはおはじきの置き場としてそのまま残します。分子構造カードは元素カードの下（プレイヤー側に挟む）でも上に重ねてもどちらでも可——元素カードのテキストが確認できれば問題ありません。配置したカードの分子式に含まれる元素の個数だけ、以降の回収判定で**毎回**免除されます。

**ルール:**
- 各元素カードに置けるのは **1枚まで**（=合計最大5枚）
- 軽減量 = 配置した分子構造カードの**その元素の個数**
- **入れ替えで枠から外したカードは手元（ストック）に戻る**（=後で分解に使える）

| 配置例 | 効果 |
|--------|------|
| 水 H₂O を **酸素枠** に配置 | O軽減=1 |
| メタン CH₄ を **水素枠** に配置 | H軽減=4 |
| グルコース C₆H₁₂O₆ を **水素枠** に配置 | H軽減=12 |

**軽減の使い方:**
酸素枠に H₂O を置いた状態（O軽減=1）で、エタノール C₂H₆O（C=2, H=6, O=1）の回収を狙うと:
- C: 必要2 → カード上の黒×2 が必要（軽減なし）
- H: 必要6 → カード上の白×6 が必要（軽減なし）
- O: 必要1 → **枠から自動的に軽減=1** で要件達成。カード上に赤おはじきが乗っていなくてもOK

> カードをコレクションするほど、各元素の軽減が積み重なって大きい分子が取りやすくなります。

**例（不要な色でも軽減が補う）**:
> 水素枠に CH₄（H軽減=4）、酸素枠に H₂O（O軽減=1）を配置済み。
> → H₂O のコスト: H=2（水素枠 CH₄ の軽減4で免除）、O=1（酸素枠 H₂O の軽減1で免除）→ **コストはすでにゼロ**。
> → 黄色おはじきを弾いて H₂O に乗せる。黄色自体はコストに貢献しないが、枠軽減ですでに全コストが免除されているので**そのまま回収成功**。
> → 不要な色のおはじきしか手元にないときも、デッキが育っていれば回収できる。これがエンジンビルディングの醍醐味。

## 分解（カード消費による一括免除）

手元（ストック）の回収済みカードを**捨てて**、そのカードに含まれる1種類の元素について、含有数分を今手番の回収判定で一括免除します。

**手順:**
1. 分解したいカードと、免除に使う**1種類の元素**を宣言する
2. そのカードを**捨て場**に出す（再利用不可）
3. 宣言した元素について、そのカードの個数分が今手番の回収判定で免除される

**重要:**
- 1枚のカードからは**1種類の元素**しか選べない（複数元素を持つカードでも1元素のみ）。選ぶ元素はプレイヤーが自由に決める（分子式に含まれる元素なら何でも可）
- 分解できるカードは**手元（ストック）のカード**と**元素枠に配置中のカード**の両方。元素枠のカードを分解する場合は枠から外して捨て場へ（軽減効果は失う）
- **同じカードを同一手番で「軽減」と「分解」の両方に使うことはできない**（枠から外した時点で分解のみ）
- 1手番で**複数枚**を同時に分解してもよい（MolOhajiki標準ルールでは1枚制限だが、MolSolitaireは複数枚がデフォルト）

### 分解の例

エタノール C₂H₆O（C=2, H=6, O=1）の回収を狙うとき、水素を一括追加したい:

| 分解するカード | 選択元素 | H への免除 |
|--------------|--------|------------|
| 水 H₂O を分解 | 水素 | +2 |
| メチル基 -CH₃ を分解 | 水素 | +3 |
| **合計（同時宣言）** | | **+5** |

カード上に白×1だけ乗っていれば、H必要6 ≤ 免除(1+5)=6 で水素要件クリアになります。

## 手詰まり（敗北）

以下の状態になった時点で **ゲーム終了（敗北）**:

- **手元のおはじきが0個**、かつ
- **手元（ストック）と元素枠に配置されたカードをすべて分解しても、グリッド上のどのカードも回収できない**

**手詰まりの例**:
> 状況: 手元おはじき 0個。盤上の水 H₂O（H=2, O=1）に白×1が乗っている。手元のカード（ストック）に -OH（ヒドロキシ基、O=1）のみ。元素枠は空。
>
> H₂O の回収を試みる:
> - H: 必要2 / 免除 = 白×1（カード上）= 1 → **1個不足**
> - -OH を分解して「水素」を選ぶ → H免除 +1 → 合計 2 → H はクリア
> - O: 必要1 / 免除 = 0（カード上に赤なし・軽減なし・分解は水素に使ってしまった）→ **O不足**
>
> 他に分解できるカードもなく、弾けるおはじきも0個 → **手詰まり（敗北）**
>
> ※ -OH を「酸素」で分解すれば O はクリアできるが、今度は H が不足になる。どちらに使っても H₂O は回収できない。

盤外へのミスが重なるほど手詰まりリスクが上がります。**おはじきの残数管理が肝**。

## ゲーム終了（勝利）と得点

**目標Lv3カード（中央の表向きカード）を回収した時点でゲーム終了**。

ゲーム終了時に使ったおはじき数を数えます。

```
使ったおはじき数 = 50（開始時の総数）− 手元に残ったおはじき数
```

**少ないほど高スコア**。

## 設計ノート

**なぜ裏向きのLv3カードをスペーサーとして並べるのか？**

滑り止めマットはおはじきも止めてしまうため、盤外に出たおはじきがたまたま隣のカードに微妙に触れて意図しない回収判定が起きることがあります。裏向きスペーサーの上に乗ったおはじきは「スペーサー上のみ」として処理されるため、誤判定を防ぐセーフティネットとして機能します。また手前スペーサーは戦略的に使えるゾーンでもあります（[手番の流れ](#手番の流れ) step 2 参照）。
