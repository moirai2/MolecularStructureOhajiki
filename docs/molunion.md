# MolUnion（みんなの分子）

**日本語** | [English](./molunion.en.md)

> 🤝 **みんなで一つのLv3分子を目指す協力エンジンビルド**：共有プールから選んで弾く。軽減を積み重ね、中央のゴールカードを全員で攻略せよ。

- **人数:** 2〜5人（4人推奨）
- **時間:** 30〜45分
- **対象:** 10歳以上

> 📘 **おはじきの色とカードの読み方は [COMPONENTS.md](./COMPONENTS.md) を参照**
> 📗 **化学用語（元素・分子式・官能基など）の解説は [GLOSSARY.md](./GLOSSARY.md) を参照**

---

## コンポーネント

- 分子構造カード（Lv1: 20枚、Lv2: 20枚、Lv3: 10枚）
- 元素カード 5枚（5種 × 1セット）
- タイトルカード 1枚
- おはじき 5色 × 各10個（計50個）
- 発射台カード 2枚
- 共有おはじきプール皿（プレイヤー側で用意。小皿や凹みのある台など）
- 滑り止めマット 1枚（プレイには必須）

---

## セットアップ

下図のように配置します（[拡大図](./molunion_setup.svg)）。

![MolUnion セットアップ図](./molunion_setup.svg)

1. **滑り止めマット**をプレイエリアに敷く
2. **Lv3カードを1枚ランダムに引き**、表向きで5×3グリッドの中央（3列目・2行目）に置く。これが**ゴールカード**
3. **Lv1カード20枚をシャッフル**し、14枚を表向き・縦向きでグリッドの残り14マスに置く。残り6枚は**Lv1山札**として盤の脇へ

   > 下図のグリッド外周（上下のLv3裏列・タイトル・左右の発射台）は**おはじきを弾くための台**。手順4-6で詳しく配置する。

   ```
          [Lv3裏 Lv3裏 タイトル Lv3裏 Lv3裏]   ← 上側プレイヤーの弾き面
          ┌──┬──┬──┬──┬──┐
          │L1│L1│L1│L1│L1│
          ├──┼──┼──┼──┼──┤
   [発射台1]│L1│L1│🎯│L1│L1│[発射台2]
          ├──┼──┼──┼──┼──┤
          │L1│L1│L1│L1│L1│
          └──┴──┴──┴──┴──┘
          [Lv3裏 Lv3裏 Lv3裏 Lv3裏 Lv3裏]    ← 下側プレイヤーの弾き面
   ```

4. **残ったLv3カード9枚**（10枚 − 中央ゴール1枚）を裏向きにする。4枚をグリッド上辺に並べ、中央に**タイトルカード**を挟む。タイトルカードは**文字が上側プレイヤーに正対する向き（180°回転）**で置く。この列はおはじきを弾くための**平らな台**として使う
5. **残ったLv3裏向き5枚**をグリッドの下辺に並べる（下側プレイヤーの弾き台）。これでLv3全10枚（中央1＋上辺4＋下辺5）を使い切る
6. **発射台カード2枚**をグリッドの左辺・右辺に置く（中央に向くように90°回転）。左右のプレイヤーはここからおはじきを弾く
7. **元素カード5枚**を盤の脇に縦に並べる。これが**共有元素枠**——回収した分子構造カードを重ねて全員の軽減を強化する場所
8. **Lv2カード20枚**をシャッフルし、**Lv2山札**として盤の脇に積む
9. **おはじき50個**を袋に入れる
10. **共有プール皿**を盤の脇に置き、袋からランダムに3個引いて並べる
11. プレイヤーは盤の周りに自由に座り、最初のプレイヤーを決める

## 基本用語

**共有プール:**
> 中央の皿に常時3個並んだおはじき。全員の「引き場」。手番ごとに減って袋から1個補充され、常に3個を維持する。

**共有元素枠:**
> 全員で使う5枚の元素カード。回収した分子構造カードを重ねることで軽減が積み重なり、**全員の**回収判定に毎回適用される。

**共有ストック:**
> 元素枠にまだ配置していない回収カードを置く場。元素枠から入れ替えで外したカードもここへ。誰の手番でも分解に使える。

**ラウンド:**
> カードが回収された手番から次の回収までの区間。回収者が次のラウンド開始者。ゲーム開始時は最初のプレイヤーが開始者。

**おはじきの行き先（3区分）:**

| 状態 | 条件 | 扱い |
|------|------|------|
| **回収対象カード上** | Lv1 / Lv2 / ゴールLv3の上に乗っている | 回収判定の対象。**回収成功時は袋へ戻す** |
| **スペーサー上** | 裏向きLv3カードの上にのみ乗っている | 回収判定対象外。手番プレイヤーが選択：①袋へ戻す ②盤に残す（次の手番以降に押し戻せる） |
| **脱落** | マットに触れている（横から見て判断） | 袋へ戻す |

> MolSolitaireと異なり、MolUnionではおはじきは消費されない。盤外に出ても袋へ戻して再利用する。

**またがりおはじき:**

複数のカードに触れているおはじきの裁定です。

1. 回収判定中は「触れているカード全てに乗っている」扱い
2. **1枚のカードにしか使えない**——カードを回収した瞬間にそのカードのものとして確定し、袋へ戻される
3. 複数のカードが同時に回収条件を満たす場合でも、またがりおはじきは**最終的に1枚のカードにしか割り当てられない**。取得する順番は手番プレイヤーが決める

> スペーサー（裏向きLv3）と回収対象カードにまたがっている場合：回収対象カード上として扱う（スペーサー側の接触は無視）。

## 1手番の流れ

```
1. 共有プールから1個選んで弾く

2. 袋からランダムに1個引いてプールを3個に戻す

3. カード回収判定をする

4. 空いたマスを補充する

5. 次のプレイヤーへ
```

---

### Step 3 詳細：カード回収判定

> **重要:** カードを回収した瞬間、そのカードに触れているおはじきは**全て袋へ戻す**。

1. 判定の**前**にカードを分解してもよい（全員で相談可。最終決定は手番プレイヤー）
2. 盤上におはじきが1個以上乗っているカードを確認する
3. 条件を満たすカードを全て回収する（取得する順番は手番プレイヤーが決める）
4. 回収したカードに触れているおはじきは**全て袋へ戻す**
5. 回収したカードを共有元素枠に配置・入れ替えするか全員で相談する（最終決定は手番プレイヤー）
6. **この手番でカードを1枚でも回収した場合**、ラウンドカウントをリセットし、この手番プレイヤーが新しいラウンド開始者になる

---

### Step 4 詳細：補充

空いたマスごとに、山札の**上から1枚を引いて**表向きで配置する。Lv1山札がある間はLv1から補充し、枯渇したらLv2から補充する。

---

## ミス条件（協力の緊張感）

**ラウンド開始者から数えて4手番以内に誰もカードを回収しなければ、1ミス。**

- 4手番固定（人数に応じた巡数の目安：2人=2巡、3人=1巡+1手番、4人=1巡、5人=4人まで）
- カードを回収した人が**新しいラウンド開始者**となり、カウントがリセットされる
- ミス計上時もカウントをリセット（次のプレイヤーから再カウント開始）
- **3ミスでゲームオーバー（全員敗北）**

---

## カード回収判定（コアメカニクス）

盤上に1個以上おはじきが乗っている**全てのカード**について、各元素ごとに以下を計算します。

```
必要量 = カードの分子式に含まれる、その元素の個数
免除量 = (そのカードに触れているおはじきのうち、その元素の色の個数)
       + (共有元素枠に置かれた分子構造カードの、その元素の個数)
       + (今手番で宣言した分解カードの、その元素の個数)

分子式に含まれるすべての元素について 必要量 ≤ 免除量 → 回収成功
```

---

## 共有元素枠への軽減（共有エンジン）

MolUnionの核心は**全員で育てる共有エンジン**です。

- 回収したカードを共有元素枠（5種類）のいずれかに配置する
- 軽減効果は**全員の**回収判定に毎回適用される
- 各枠に置けるのは**1枚まで**。入れ替えたカードは**共有ストック**へ
- どの枠に配置するかは全員で相談できる（最終決定は手番プレイヤー）

| 配置例 | 効果 |
|--------|------|
| 水 H₂O を**酸素枠**に配置 | 全員のO軽減=1 |
| メタン CH₄ を**水素枠**に配置 | 全員のH軽減=4 |
| グルコース C₆H₁₂O₆ を**水素枠**に配置 | 全員のH軽減=12 |

---

## 分解（カード消費による一括免除）

**共有ストック**または**共有元素枠**のカードを捨てて、そのカードに含まれる1種類の元素について、含有数分を今手番の回収判定で一括免除します。

- 1枚のカードからは**1種類の元素**しか選べない
- 分解したカードは捨て場へ。**共有元素枠から取った場合は軽減効果も失う**
- 手番プレイヤーが宣言するが、どのカードを分解するかは全員で相談できる（最終決定は手番プレイヤー）
- 1手番で複数枚を同時に分解してもよい

---

## ゲーム終了

**ゴールカード（中央のLv3）を回収した時点で全員の勝利。**

| 記録項目 | 内容 |
|----------|------|
| **回収カード総数** | ゴールカードを含む全回収枚数 |
| **ミス数** | 0〜2 |

```
スコア = 回収カード総数 × (ミス数 + 1)
```

**数字が小さいほど高スコア。** 同じゴールカードでスコア更新を狙うのがリプレイの楽しみ。

---

## 戦略のヒント

- **ゴール確認から始める**: ゲーム開始直後にゴールLv3の分子式を全員で確認し、「どの元素を重点的に育てるか」を共有
- **エンジンを育てる発想**: ゴールLv3を直接回収するのは現実的でない。共有元素枠を育てて**ゴール分子式の各元素について必要量がゼロに近くなるまで**軽減を積み上げる
- **補充の相談**: Lv2は着地が難しいが軽減効果が大きく、スコア改善に効く
- **分解の使いどころ**: 共有ストックに溜まったカードは分解で一気に免除できる
- **ミス回避**: ラウンド開始から4手番以内に必ず誰かがLv1を回収してリセット
