# MolUnion（分子共闘）

**日本語** | [English](./molunion.en.md)

> 🤝 **みんなで一つのLv3分子を目指す協力エンジンビルド**：共有プールから選んで弾く。軽減を積み重ね、中央のゴールカードを全員で攻略せよ。

- **人数:** 2〜5人（4人推奨）
- **時間:** 30〜45分
- **対象:** 10歳以上

> 🎴 **基本ルールは [MolSolitaire](./solitaire.md) と同じ**：カード回収判定・分解・元素枠への軽減はソリティア版を踏襲。MolUnionはこの元素枠を全員で共有する協力ゲームに拡張したものです（盤外おはじきは袋に戻す・共有プールから1個選択など細部は本文で確認）。
> 📘 **おはじきの色とカードの読み方は [COMPONENTS.md](./COMPONENTS.md) を参照**
> 📗 **化学用語（元素・分子式・官能基など）の解説は [GLOSSARY.md](./GLOSSARY.md) を参照**

---

## コンポーネント

- 分子構造カード（Lv1: 20枚、Lv2: 20枚、Lv3: 10枚）
- 元素カード 5枚（5種 × 1セット）
- タイトルカード 1枚
- おはじき 5色 × 各10個（計50個）
- 発射台カード 2枚
- 共有おはじきプール皿（プレイヤー側で用意。小皿や凹みのある台など）
- 滑り止めマット 1枚（プレイには必須）

---

## セットアップ

下図のように配置します（[拡大図](./molunion_setup.svg)）。

![MolUnion セットアップ図](./molunion_setup.svg)

1. **滑り止めマット**をプレイエリアに敷く
2. **Lv3カードを1枚ランダムに引き**、表向きで5×3グリッドの中央（3列目・2行目）に置く。これが**ゴールカード**
3. **Lv1カード20枚をシャッフル**し、14枚を表向き・縦向きでグリッドの残り14マスに置く。残り6枚は**Lv1山札**として盤の脇へ

   > 下図のグリッド外周（上下のLv3裏列・タイトル・左右の発射台）は**おはじきを弾くための台**。手順4-6で詳しく配置する。

   ```
          [Lv3裏 Lv3裏 タイトル Lv3裏 Lv3裏]   ← 上側プレイヤーの弾き面
          ┌──┬──┬──┬──┬──┐
          │L1│L1│L1│L1│L1│
          ├──┼──┼──┼──┼──┤
   [発射台1]│L1│L1│🎯│L1│L1│[発射台2]
          ├──┼──┼──┼──┼──┤
          │L1│L1│L1│L1│L1│
          └──┴──┴──┴──┴──┘
          [Lv3裏 Lv3裏 Lv3裏 Lv3裏 Lv3裏]    ← 下側プレイヤーの弾き面
   ```

4. **残ったLv3カード9枚**（10枚 − 中央ゴール1枚）を裏向きにする。4枚をグリッド上辺に並べ、中央に**タイトルカード**を挟む。タイトルカードは**文字が上側プレイヤーに正対する向き（180°回転）**で置く。この列はおはじきを弾くための**平らな台**として使う
5. **残ったLv3裏向き5枚**をグリッドの下辺に並べる（下側プレイヤーの弾き台）。これでLv3全10枚（中央1＋上辺4＋下辺5）を使い切る
6. **発射台カード2枚**をグリッドの左辺・右辺に置く（中央に向くように90°回転）。左右のプレイヤーはここからおはじきを弾く
7. **元素カード5枚**を盤の脇に縦に並べる。これが**共有元素枠**——買った分子構造カードを重ねて全員の軽減を強化する場所
8. **Lv2カード20枚**をシャッフルし、**Lv2山札**として盤の脇に積む
9. **おはじき50個**を袋に入れる
10. **共有プール皿**を盤の脇に置き、袋からランダムに3個引いて並べる
11. プレイヤーは盤の周りに自由に座り、最初のプレイヤーを決める

## 基本用語

**共有プール:**
> 中央の皿に常時3個並んだおはじき。全員の「引き場」。手番ごとに減って袋から1個補充され、常に3個を維持する。

**共有元素枠:**
> 全員で使う5枚の元素カード。回収した分子構造カードを重ねることで軽減が積み重なり、**全プレイヤー全員の**回収判定に毎回適用される。

**共有ストック:**
> 元素枠にまだ配置していない回収カードを置く場。元素枠から入れ替えで外したカードもここへ。誰の手番でも分解に使える。

**ラウンド:**
> 「カード購入」から「次のカード購入」までの区切り。ゲーム開始時のラウンド開始者は最初のプレイヤー。カードを購入した人が新しいラウンド開始者となり、カウントがリセットされる。

**盤上・盤外の判定:**
> おはじきが静止した時点で、**マットに触れていなければ盤上**、触れていれば**盤外**（横から見て判断）。盤外に出たおはじきは**袋に戻す**（[MolSolitaire](./solitaire.md) と異なり消費されない）。

**またがりおはじき（量子力学モデル）:**
> 複数のカードに触れている場合、触れているカード全てに乗っている扱い。**回収判定の瞬間**にプレイヤーがどのカードに割り当てるか選んで確定する。

## 1手番の流れ

```
1. 共有プールから1個選んで弾く

2. 袋からランダムに1個引いてプールを3個に戻す

3. カード回収判定をする
   - 判定の前にカードを分解してもよい
   - 条件を満たすカードがあれば回収する
   - 回収したカードは全員で相談して共有元素枠に配置する

4. 空いたマスをLv1またはLv2から補充する（どちらにするか全員で相談）

5. 次のプレイヤーへ
```

---

## ミス条件（協力の緊張感）

**ラウンド開始者から数えて4手番以内に誰もカードを購入しなければ、1ミス。**

- 4手番固定（人数に応じて1〜2巡）
- カードを購入した人が**新しいラウンド開始者**となり、カウントがリセットされる
- ミス計上時もカウントをリセット（次のプレイヤーから再カウント開始）
- **3ミスでゲームオーバー（全員敗北）**

---

## カード回収判定（コアメカニクス）

[MolSolitaire](./solitaire.md) と同じ計算式を全員で共有します。

```
必要量 = カードの分子式に含まれる、その元素の個数
免除量 = (そのカードに触れているおはじきのうち、その元素の色の個数)
       + (共有元素枠に置かれた分子構造カードの、その元素の個数)
       + (今手番で宣言した分解カードの、その元素の個数)

分子式に含まれるすべての元素について 必要量 ≤ 免除量 → 回収成功
```

---

## 共有元素枠への軽減（共有エンジン）

MolUnionの核心は**全員で育てる共有エンジン**です。

- 回収したカードを共有元素枠（5種類）のいずれかに配置する
- 軽減効果は**全プレイヤー全員の**回収判定に毎回適用される
- 各枠に置けるのは**1枚まで**。入れ替えたカードは**共有ストック**へ
- どの枠に配置するかは**全員で相談**して決める

| 配置例 | 効果 |
|--------|------|
| 水 H₂O を**酸素枠**に配置 | 全員のO軽減=1 |
| メタン CH₄ を**水素枠**に配置 | 全員のH軽減=4 |
| グルコース C₆H₁₂O₆ を**水素枠**に配置 | 全員のH軽減=12 |

---

## 分解（カード消費による一括免除）

**共有ストック**または**共有元素枠**のカードを捨てて、そのカードに含まれる1種類の元素について、含有数分を今手番の回収判定で一括免除します。

- 1枚のカードからは**1種類の元素**しか選べない
- 分解したカードは捨て場へ。**共有元素枠から取った場合は軽減効果も失う**
- 手番プレイヤーが宣言するが、どのカードを分解するかは**全員で相談**できる
- 1手番で複数枚を同時に分解してもよい

## ゲーム終了

**ゴールカード（中央のLv3）を回収した時点で全員の勝利。**

| 記録項目 | 内容 |
|----------|------|
| **購入カード総数** | ゴールカードを含む全購入枚数 |
| **ミス数** | 0〜2 |

```
スコア = 購入カード総数 × (ミス数 + 1)
```

**数字が小さいほど高スコア。** 同じゴールカードでスコア更新を狙うのがリプレイの楽しみ。

---

## 戦略のヒント

- **ゴール確認から始める**: ゲーム開始直後にゴールLv3の分子式を全員で確認し、「どの元素を重点的に育てるか」を共有
- **デッキを育てる発想**: ゴールLv3を直接買うのは現実的でない。共有元素枠を育てて**ゴール分子式の各元素について必要量がゼロに近くなるまで**軽減を積み上げる
- **補充の相談**: Lv2は着地が難しいが軽減効果が大きく、スコア改善に効く
- **分解の使いどころ**: 共有ストックに溜まったカードは分解で一気に免除できる
- **ミス回避**: ラウンド開始から4手番以内に必ず誰かがLv1を購入してリセット
