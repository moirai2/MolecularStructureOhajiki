# 分子構造おはじきゲーム

**日本語** | [English](README.en.md)

日本の伝統的な遊び「おはじき」と化学の分子構造を組み合わせた、遊びながら学べる教育的ボードゲームです。

**ゲームマーケット2026春 出展済み**

---

## 基本情報

- **プレイ人数:** 1〜5人（ゲームによって異なる。MolOhajiki本編は2人専用、MolSurvivalは3〜4人推奨）
- **対象年齢:** 10歳以上（TicTacMol・MolSurvivalなど一部のゲームは6歳から遊べます。MolPuzzleは12歳以上推奨）
- **プレイ時間:** 10〜45分（ゲームによって異なる）
- **ジャンル:** デクステリティ × エンジンビルディング（手元のカードを育てて得点力を伸ばすゲームスタイル） × 理科を遊びながら学べる教育ゲーム

---

## はじめての方へ

1. まず **[コンポーネント一覧](docs/COMPONENTS.md)** でカードの読み方とおはじきの色を確認してください
2. 遊びたいゲームのルールを読んでください（[ゲーム一覧](#ゲーム一覧) からリンク）
3. 化学用語が気になったら **[化学用語ガイド（GLOSSARY）](docs/GLOSSARY.md)** を参照してください（読まなくても遊べます）

初回は **TicTacMol**（2人・15分・シンプルなルール）または **MolPuzzle**（1人・パズル形式）から始めるのがおすすめです。

## コンポーネント（1セット）

詳細・分子構造カードチェックリストは → **[コンポーネント一覧](docs/COMPONENTS.md)**

- **分子構造カード:** 50枚（Lv1×20、Lv2×20、Lv3×10）
- **元素カード:** 10枚（5種×2）
- **プレイヤーカード:** 2枚（おはじきの発射台）
- **タイトルカード:** 1枚（表: タイトル＋クレジット、裏: QRコード）
- **カード合計:** 63枚
- **おはじき:** 50個（各色10個：黒・白・赤・青・黄）※ルール文書内の色名。黒＝緑、白＝水色（詳細は [COMPONENTS.md](docs/COMPONENTS.md)）
