# Molecular Structure Ohajiki

[日本語](README.md) | **English**

A board game that combines *ohajiki* — a traditional Japanese flicking game using small glass marbles — with the molecular structures of chemistry. Learn while you play.

**Exhibiting at Game Market 2026 Spring (Tokyo)**

---

## At a glance

- **Players:** 1–5 (depends on the game; MolOhajiki main game is 2-player only, MolSurvival is best with 3–4)
- **Age:** 10+ (TicTacMol and MolSurvival can be played from age 6)
- **Play time:** 10–45 minutes (depends on the game)
- **Genre:** Dexterity × Engine-building × Science-themed educational game

---
